# Papamo SMS

Create commits only when requested. Never sign commits as an AI or add AI attribution. Omit Co-authored-by, Signed-off-by, generated-by footers, assistant names, and similar trailers from commits made by agents. Never impersonate the user, add a DCO sign-off on their behalf, or use their signing key. Use git commit --no-gpg-sign without --signoff when authorized to commit. Preserve the user's existing Git configuration.

The Rust service receives messages from an iPhone Shortcut. Keep the HTTP contract platform-neutral for future Android clients. Run cargo fmt --check, cargo clippy --locked --all-targets -- -D warnings, and cargo test --locked before delivery. Preserve all targets in CI. Never log message bodies, senders, or credentials.
